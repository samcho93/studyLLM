학습은 새로운 것이 아니다

머신러닝 기초 과정에서 신경망을 학습시킬 때 쓴 말이 그대로 나온다. 에폭(epoch), 배치(batch), 학습률(learning rate), 옵티마이저(optimizer), 손실 곡선. 달라진 것은 두 가지다. 정답 레이블이 따로 없고 다음 글자 자체가 정답이라는 것(자기 지도 학습), 그리고 분류할 클래스가 2~10개가 아니라 글자 495종이라는 것이다.

3개념

① 학습 데이터: 창 하나에 문제 T개

언어 모델의 학습 데이터는 따로 만들 필요가 없다. 코퍼스에서 길이 T인 창(window)을 하나 잘라 입력 x로 쓰고, 그 창을 한 칸 민 것을 정답 y로 쓴다. 인과 마스크(5주차) 덕분에 위치 t는 x₀…xt만 볼 수 있으므로, 창 하나에 “다음 글자 맞히기” 문제가 T개 들어 있다.

학습에 쓰는 글은 코퍼스 17문서 중 16문서, 6,470자다. “벡터 데이터베이스와 인덱스” 문서(rag-vectordb, 356자)는 떼어 두고 검증(validation)에만 쓴다. 모델이 한 번도 보지 않은 글을 얼마나 잘 맞히는지가 “진짜 실력”이다.

② 학습 루프: 다섯 줄의 반복

for (let step = 1; step <= 2000; step++) {
  const { x, y } = getBatch(train, B, T, rand);   // ① 무작위 위치에서 창 B개
  opt.zeroGrad();                                 //    지난 스텝의 기울기 지우기
  const { loss } = forward(model, x, B, T, y);    // ②③ 순전파 → 교차 엔트로피
  backward(loss);                                 // ④ 모든 파라미터의 .grad 채우기
  opt.clip(1);                                    // ⑤ 기울기 노름이 1보다 크면 줄이기
  opt.step(lrAt(step));                           //    AdamW로 한 걸음
}
  • AdamW: 4주차의 경사 하강법은 모든 가중치를 같은 학습률로 옮겼다. AdamW는 가중치마다 최근 기울기의 평균(방향)과 크기(흔들림)를 기억해, 자주 크게 흔들리는 가중치는 조심스럽게, 꾸준한 가중치는 과감하게 옮긴다. 이름의 W는 가중치를 조금씩 0 쪽으로 당기는 가중치 감쇠(weight decay)다.
  • 기울기 자르기(gradient clipping): 모든 기울기를 한 벡터로 본 길이(노름)가 1을 넘으면 길이 1로 줄인다. 가끔 나오는 거대한 기울기 하나가 학습을 망치는 것을 막는다. 위젯의 “기울기 노름”이 이 값이다.

③ 손실 읽는 법: 출발점은 ln 495

학습 전 모델은 가중치가 0에 가까운 작은 수라 모든 글자에 거의 같은 확률 1/495를 준다. 정답 글자의 확률이 1/495면 교차 엔트로피는 −ln(1/495) = ln 495 ≈ 6.20이다. 실제로 재 보면 6.20~6.21이 나온다(C2, 위젯의 첫 화면). 초기 손실이 이 값과 크게 다르면 초기화나 코드에 문제가 있다는 뜻이다.

손실 L은 “매번 약 eL개 후보 중에서 고르는 정도로 헷갈린다”로 읽을 수 있다. 6.2면 495개 전부, 4.16(1주차 바이그램의 검증 NLL)이면 약 64개, 2면 약 7개, 1이면 약 3개다. 9주차에 이 값을 퍼플렉서티라는 이름으로 다시 만난다.

표를 위에서부터 읽으면 모델이 배우는 순서가 보인다. 먼저 자주 나오는 글자(공백, “다”, “.”)를 배우고, 다음에 “토큰”, “임베딩” 같은 글자 묶음을, 그다음에 어절 길이와 “~다.”로 끝나는 문장 모양을 배운다. 그런데 표의 오른쪽 두 열을 보면 이상한 점이 있다. 학습 손실은 끝까지 내려가는데 검증 손실은 4 근처에서 멈췄다가 다시 올라간다. ⑤에서 이 문제를 다룬다.

④ 학습률: 한 걸음의 크기

학습률은 ⑤에서 가중치를 얼마나 멀리 옮길지 정한다. 이번 주 엔진은 학습률을 고정하지 않고 워밍업(warmup) + 코사인 감소 스케줄을 쓴다. 처음 30스텝은 0에서 최대값까지 천천히 올리고(무작위 가중치에서 나오는 큰 기울기로 크게 움직이지 않도록), 그 뒤 2,000스텝까지 코사인 곡선을 따라 최대값의 10%로 줄인다(끝에서는 미세 조정).

최대 학습률만 바꿔 기본 모델을 500스텝씩 학습시킨 결과다.

⑤ 과대적합: 학습 손실만 보면 속는다

학습 손실은 끝까지 내려간다. 그러나 학습에 쓰지 않은 문서의 손실은 125스텝에서 3.88로 가장 낮았고, 그 뒤로는 제자리를 지키다 600스텝쯤부터 올라가 2,000스텝에서는 6.43이 된다. 처음 모델(6.22)보다도 나쁘다. 모델이 “한국어 글의 규칙”이 아니라 “이 16개 문서 자체”를 외우고 있다는 뜻이다. 이것이 과대적합(overfitting)이다.

이유는 데이터 크기다. 한 스텝에 256글자를 보므로 6,470자짜리 코퍼스는 약 25스텝마다 한 번씩 다시 본다. 2,000스텝이면 같은 글을 79번 반복해서 본 셈이다. 미리 학습해 둔 “완성 모델”(D48 · 2층 · 문맥 48, 3,000스텝, 약 356에폭)은 더 극단적이다. 학습 손실 0.12, 검증 손실 9.40이고, “실습실은”을 주면 코퍼스 문장을 한 글자도 틀리지 않고 베낀다.

실습실은 본관 3층 305호와 306호를 사용하며, 각 실습실에는 GPU가 장착된 PC 30대가 있다.↵↵수료 요건

잘 쓴 문장처럼 보이지만 새로 만든 문장이 아니다. 1주차에 n = 5인 n-gram이 문서를 베끼던 것과 같은 현상이 신경망에서도 일어난다. 참고로 기본 모델의 검증 손실 최저값 3.88은 1주차 바이그램의 검증 NLL 4.16보다 낮다. 외우기 전의 신경망은 빈도표보다 처음 보는 글을 잘 맞힌다. 검증 손실이 가장 낮을 때 멈추는 조기 종료(early stopping)와 평가 지표는 9주차에 다룬다.

⑥ 모델 크기와 속도

위젯에서 바꿀 수 있는 세 가지 크기와 파라미터 수다(문맥 32 기준). 흥미롭게도 기본 모델은 파라미터의 절반 이상(57%)이 트랜스포머 블록이 아니라 임베딩 표와 출력층에 있다. 글자 495종마다 D차원 벡터가 입구와 출구에 하나씩 필요하기 때문이다.

머신러닝 기초와 연결 — 머신러닝 기초의 신경망 단원에서 본 “에폭 · 배치 · 학습률 · 학습/검증 곡선”이 그대로 나온다. 차이는 규모와 정답의 출처뿐이다. 거기서 검증 정확도가 떨어지기 시작하면 학습을 멈췄던 것처럼, 여기서도 검증 손실이 올라가기 시작하는 지점이 멈출 때다.

4실습

미니 GPT가 이 페이지의 백그라운드 워커(Web Worker)에서 학습한다. 학습하는 동안에도 스크롤과 다른 조작이 멈추지 않는다. 손실 곡선, 스텝당 시간, 샘플 변천사는 오른쪽 실행 결과 창에 나온다(휴대폰에서는 위젯 바로 아래). 샘플은 50스텝마다 같은 시작 글자·같은 seed로 뽑으므로 달라지는 것은 모델뿐이다. 물결 밑줄은 코퍼스에 그대로 있는 10자 이상의 구간(외운 부분)이다.

기본 설정 2,000스텝은 컴퓨터에 따라 3~5분 걸린다. 탭을 다른 곳으로 옮기면 브라우저가 워커를 느리게 돌릴 수 있다. 설정을 바꾸면 ⟲ 처음부터로 새 모델을 만들고, 이전 곡선은 회색 점선으로 남는다.

관찰 질문

  1. 학습 전 상태의 손실과 샘플을 본다. 손실이 ln 495 ≈ 6.20에 가까운 이유를 “모든 글자에 같은 확률”로 설명한다.

6정리 & 다음 주 예고

  • 언어 모델의 학습 데이터는 글 자체다. 길이 T인 창 x와 한 칸 민 y가 (입력, 정답)이고, 창 하나에 문제가 T개 들어 있다.
  • 학습 = 배치 뽑기 → 순전파 → 교차 엔트로피 → 역전파 → (기울기 자르기) → AdamW 업데이트의 반복이다. 가중치를 바꾸는 곳은 마지막 한 줄뿐이다.
  • 학습 전 손실은 ln V(≈ 6.20)에서 시작한다. 손실 L은 “약 eL개 후보 중에서 고르는 정도”로 읽는다.
  • 학습률이 너무 크면 정체하거나 발산하고, 너무 작으면 느리다. 워밍업 + 코사인 스케줄이 흔한 절충이다.
  • 학습 손실만 보면 속는다. 작은 코퍼스를 오래 학습하면 검증 손실이 올라가고 모델은 문서를 그대로 외운다(과대적합).

다음 주(8주차 디코딩 전략)에는 이번 주 모델을 그대로 가져와 “확률 분포에서 다음 글자를 어떻게 고를까”를 다룬다. 이번 주 샘플은 모두 온도 0.8로 뽑았다. 온도를 0으로 내리면, 2로 올리면, 상위 k개에서만 뽑으면 같은 모델의 글이 어떻게 달라지는지 샘플링 조절판으로 실험한다.
