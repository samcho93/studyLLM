  • 가중치 58,671개가 작은 무작위 수 → 모든 글자에 거의 같은 확률 1/495
  • 교차 엔트로피 = −ln(1/495) = ln 495 ≈ 6.20 (실측 6.20~6.21)
  • 1주차 n-gram: 세면 끝 · 신경망: 셀 수 없다 → 조금씩 고치기를 수천 번

발문: “아무것도 모르는 모델의 손실은 얼마여야 할까?” 4주차 교차 엔트로피 식으로 칠판에서 ln 495를 같이 계산한다.

초기 손실 확인은 실무에서도 첫 번째 점검 항목이다. 이 값에서 크게 벗어나면 초기화나 손실 코드가 틀린 것이다(C2의 “×30” 실험).

표는 Challenge C1의 실제 출력이다. “레이블링 비용이 0”이라는 점이 LLM이 인터넷 전체로 학습할 수 있는 이유라고 짚는다(자기 지도 학습).

5주차 인과 마스크를 다시 소환한다. 마스크가 없으면 위치 3이 위치 4(정답)를 훔쳐볼 수 있어 문제가 성립하지 않는다.

학습 루프: 다섯 줄의 반복

for (let step = 1; step <= 2000; step++) {
  const { x, y } = getBatch(train, B, T, rand);  // ① 문제 뽑기
  opt.zeroGrad();
  const { loss } = forward(model, x, B, T, y);   // ②③ 순전파 → 교차 엔트로피
  backward(loss);                                // ④ 역전파 (4주차)
  opt.clip(1);                                   // ⑤ 기울기 자르기
  opt.step(lrAt(step));                          //    AdamW로 한 걸음
}
  • AdamW: 가중치마다 기울기의 평균·크기를 기억해 걸음 폭을 따로 정한다 + 가중치 감쇠
  • clip(1): 전체 기울기 길이가 1을 넘으면 1로 줄인다 → 가끔 나오는 거대한 기울기 방지

MLBasic 신경망 단원의 학습 루프(순전파 → 손실 → 역전파 → 가중치 갱신)와 한 줄씩 대응시킨다. 새로운 것은 ① 배치를 무작위 창으로 만든다는 것뿐이다.

자주 나오는 질문: “zeroGrad를 왜 하나?” → backward는 .grad에 더한다. 지우지 않으면 지난 스텝 기울기가 쌓인다. C3에서 빼 보면 AdamW 덕분에 손실은 그럭저럭 내려간다(부록 B C3 참고). “돌아가는 것과 맞는 것은 다르다”를 보여 주기 좋다.

150스텝 학습, 코드로 직접

import { loadCorpus, corpusText, charVocab } from '/assets/js/core/text.js';
import { createModel, createTrainer, evaluate, generate } from '/assets/js/core/gpt.js';
const corpus = await loadCorpus();
const vocab = charVocab(corpusText(corpus));
const data = Int32Array.from(vocab.encode(corpusText(corpus)));
const model = createModel({ vocabSize: vocab.size, blockSize: 16, nLayer: 1, nHead: 4, nEmbd: 16 }, 1337);
const trainer = createTrainer(model, data, { batchSize: 8, lr: 1e-2, warmup: 10, totalSteps: 150 });
const say = (step) => {
  const loss = evaluate(model, data, { windows: 8 }).toFixed(2);
  const text = vocab.decode(generate(model, vocab.encode('실습실은'), 30, { temperature: 0.8, seed: 3 }).ids);
  console.log(`step ${step}  손실 ${loss} | ${text.replace(/\n/g, '↵')}`);
};
say(0);
for (let step = 1; step <= 150; step++) {
  trainer.step(); // 배치 → 순전파 → 역전파 → AdamW
  if (step % 50 === 0) say(step);
}

아주 작은 모델(D16 · 1층 · 문맥 16, 파라미터 19,903개)이라 3~4초면 끝난다. 실행 결과: step 0 손실 6.21 글자 수프 → step 50 4.18 → step 100 3.45 → step 150 3.27 “실습실은 3방U 벡터 단어 가 벡터을 이 유보습로 토큰인다.”

createTrainer 안에 슬라이드 5의 다섯 줄이 들어 있다. C3에서 학생이 직접 푼다.

정리

  • 학습 데이터 = 글 자체: 창 x와 한 칸 민 y, 창 하나에 문제 T개
  • 학습 = 배치 → 순전파 → 교차 엔트로피 → 역전파 → 자르기 → AdamW의 반복
  • 출발점 ln V ≈ 6.20 · 손실 L은 “eL개 중에서 헷갈림”
  • 학습률: 크면 정체·발산, 작으면 느림 · 워밍업 + 코사인
  • 작은 코퍼스를 오래 학습하면 외운다 — 검증 손실을 본다

import { loadCorpus, corpusText, charVocab } from '/assets/js/core/text.js';
import { createModel, forward, getBatch, paramCount } from '/assets/js/core/gpt.js';
import { mulberry32 } from '/assets/js/core/rng.js';
const corpus = await loadCorpus();
const vocab = charVocab(corpusText(corpus));
const data = Int32Array.from(vocab.encode(corpusText(corpus)));
const config = { vocabSize: vocab.size, blockSize: 32, nLayer: 2, nHead: 4, nEmbd: 32 };
const model = createModel(config, 1337);
console.log('파라미터 수:', paramCount(model));
const B = 8;
const T = config.blockSize;
const { x, y } = getBatch(data, B, T, mulberry32(1));
const { logits, loss } = forward(model, x, B, T, y);
const loss0 = loss.data[0];
const lnV = Math.log(vocab.size);
console.log('학습 전 손실:', loss0.toFixed(4), ' ln V:', lnV.toFixed(4));
const V = vocab.size;
const row = Array.from(logits.data.subarray(0, V));
const m = Math.max(...row);
const ex = row.map((v) => Math.exp(v - m));
const sum = ex.reduce((a, b) => a + b, 0);
const p = ex.map((e) => e / sum);
console.log('첫 위치 확률 최대/최소:', Math.max(...p).toFixed(5), Math.min(...p).toFixed(5), ' 1/V =', (1 / V).toFixed(5));
const W = model.params.headW.data;
for (let i = 0; i < W.length; i++) W[i] *= 30;
console.log('출력층 가중치 ×30 후 손실:', forward(model, x, B, T, y).loss.data[0].toFixed(4));

해석: 초기 가중치 표준편차가 0.02로 작아 logits가 0 근처 → 소프트맥스가 거의 균등. 출력층을 키우면 무작위로 “확신”하는 모델이 되어 틀린 글자에 높은 확률을 주므로 손실이 ln V보다 훨씬 크다. 학습은 그 잘못된 확신을 먼저 지우느라 시간을 낭비한다.

async function loadModel(step) {
  const res = await fetch(`/assets/data/models/mini-gpt-${step}.json`);
  if (!res.ok) return null;
  return deserialize(await res.json());
}

function longestCopy(gen, source) {
  let best = '';
  for (let i = 0; i < gen.length; i++) {
    let L = best.length + 1;
    while (i + L <= gen.length && source.includes(gen.slice(i, i + L))) {
      best = gen.slice(i, i + L);
      L++;
    }
  }
  return best;
}

function copyRate(gen, source, min = 10) {
  let copied = 0;
  let i = 0;
  while (i < gen.length) {
    let L = 0;
    while (i + L < gen.length && source.includes(gen.slice(i, i + L + 1))) L++;
    if (L >= min) {
      copied += L;
      i += L;
    } else i++;
  }
  return copied / gen.length;
}
