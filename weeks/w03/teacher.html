오늘 할 수 있게 되는 것

  1. 원-핫 벡터의 코사인이 모두 0인 이유와 분포 가설을 설명한다

오늘의 nearest()(코사인 최근접)는 RAG 과정 검색기의 핵심 연산이고, 임베딩 표는 4주차 신경망 언어 모델과 7주차 미니 GPT의 첫 층이 된다.

원-핫: 공평하지만 아무것도 모른다

확률  = [0 0 1 0 0 … 0]      cos(a, b) = a · b / (|a| |b|)
온도  = [0 0 0 0 1 … 0]
실습실 = [0 1 0 0 0 … 0]      → 어떤 두 단어든 a · b = 0 → cos = 0, 거리 = √2
  • 번호의 크기 차이는 사라졌다 (공평)
  • 대신 모든 단어가 서로 직각 — “확률 ≈ 온도”를 표현할 방법이 없다

MLBasic의 BoW는 원-핫을 더한 것이다. 그래서 BoW도 “재미없다”와 “지루하다”가 비슷하다는 것을 모른다고 연결한다.

C1 기대 결과: 유사도 표의 대각선만 1, 거리는 모두 1.414.

단어는 어울리는 단어를 보면 안다

“온도를 낮추면 ___가 뾰족해진다”

  • 빈칸에 “확률”도 “분포”도 들어간다 → 둘은 비슷한 자리에 나온다
  • 분포 가설: 비슷한 문맥에 나오는 단어는 뜻도 비슷하다 (Firth, 1957)
  • 뜻을 정의하지 않고 주변 단어로 대신한다

빈칸 게임: 모르는 단어로 해 본다. “나는 어제 ○○○를 한 그릇 먹었다. ○○○는 매콤하고 국물이 진했다.” → 학생들은 ○○○가 음식이라는 것을 안다. 단어를 몰라도 주변 단어로 뜻을 짐작했다.

이 코퍼스에도 분포 가설 문장이 있다(llm-embedding 문서). 오늘 그 문서를 포함한 17문서로 직접 확인한다.

어휘 × 어휘 행렬의 한 행 = 단어 벡터 (279차원, 0 아닌 칸 3.9%)

단어는 공백·부호로 자르고 흔한 조사·어미 하나를 뗀다(cooc.js의 PARTICLES). 형태소 분석기가 아니라서 “계산하”, “고르” 같은 조각이 남는다. 학생이 물으면 “일부러 단순하게 했다, 결과가 완벽하지 않은 이유 중 하나”라고 답한다.

1주차 빈도표와 비교: 그때는 “바로 다음 글자”만, 지금은 “앞뒤 이웃 전부”. 방향을 버리고 이웃 관계만 본다.

발문: “토큰이 1등인 것은 확률과 토큰이 특별한 사이라서인가?” → 토큰은 가장 흔한 단어(36번)다. 다음 슬라이드로.

PPMI: “우연보다 몇 배 더 만났나”

PMI(w, c) = log( P(w, c) / (P(w) · P(c)) )      PPMI = max(PMI, 0)
“확률”의 이웃12345
횟수뽑는다 .64다음 .64보고 .631보다 .62top .60
PPMI샘플링 .57높은 .511보다 .44토큰 .44온도 .41

허브(이웃 목록 단골, 이웃 8개 기준): 횟수 바이그램 38 · 다음 32 · 확률 31 → PPMI 청크 18 · 확률 16 · 어텐션 16

PMI 직관: 두 단어가 독립이라면 P(w)·P(c)만큼 만날 것이다. 실제로 그보다 많이 만났으면 양수, 적으면 음수. 음수는 “데이터가 적어 우연히 못 만났을” 가능성이 커서 0으로 자른다.

약점도 바로 말한다: 두 번만 나온 단어가 한 번 겹치면 PMI가 커진다. “확률” PPMI 벡터의 큰 칸은 바꾼다 · 샘플링 · 고르 · 나누어 · top — 빈도 2~3짜리들이다(C4).

데모 · 임베딩 공간 탐색기

시연 순서 (결과는 오른쪽 실행 결과 창)

  1. ① 원-핫 · “확률”: 이웃 8개가 모두 0.00, 순서는 빈도순(토큰 · 모델 · 벡터…). 유사도 표는 대각선만 1. 지도는 원 위에 균등 배치
  2. ② 횟수: 결과 상자 “가장 큰 칸 = 토큰(8회, 빈도 36)”. 허브 바이그램 38회. 평균 코사인 0.058
  3. ③ PPMI: 이웃에 샘플링 · 온도가 올라온다. 평균 코사인 0.036으로 내려간다. ⚠ 드묾 표시를 짚는다
  4. ④ SVD k = 30: “확률” 이웃 샘플링 .88 · 뽑는다 .85 · top .85. 유사도 표에 디코딩(토큰 · 확률 · 온도 .62~.77)과 벡터(벡터 · 코사인 .58) 블록
  5. k = 2 → “모두가 이웃이다”(1등 이웃 1.00). k = 100 → PPMI에 가까워짐
  6. “임베딩”을 눌러 엉뚱한 이웃(비용 · 못)을 보여 준다. “데이터가 1,626단어뿐이라서”

  • k가 너무 작으면 모두가 한 방향, 너무 크면 희소한 원본과 같아진다

흔한 단어 50개의 평균이다(C5 정답 표). SVD는 거듭제곱 반복으로 구한다: 무작위 벡터 k개에 MᵀM을 곱하고 그람-슈미트로 직교화하기를 40번.

MLBasic 8강 PCA와 같은 계산이라고 연결한다. 위젯 2D 지도도 PCA인데, 2D에 담긴 분산은 SVD 30차원에서 9.4%뿐 → “지도는 참고, 판단은 이웃 표로”.

원-핫 × 표 = 표의 한 행

import { corpusWords, buildVocab, cooccurrence, ppmi, truncatedSVD, row } from '/assets/js/core/cooc.js';
const corpus = await (await fetch('/assets/data/corpus/corpus.json')).json();
const docs = corpusWords(corpus);
const vocab = buildVocab(docs, 2);
const E = truncatedSVD(ppmi(cooccurrence(docs, vocab, 3)), 8).vectors; // 임베딩 표: 279 × 8
const i = vocab.index.get('확률');
const onehot = new Float64Array(vocab.size);
onehot[i] = 1;
const viaMatmul = [];                                   // 원-핫 (1 × 279) · 표 (279 × 8)
for (let d = 0; d < E.cols; d++) {
  let s = 0;
  for (let r = 0; r < E.rows; r++) s += onehot[r] * E.data[r * E.cols + d];
  viaMatmul.push(s);
}
console.log('원-핫 × 표 :', viaMatmul.map((x) => x.toFixed(3)).join(' '));
console.log(`표의 ${i}번 행:`, Array.from(row(E, i), (x) => x.toFixed(3)).join(' '));
console.log('이 표의 파라미터:', E.rows * E.cols, '개 · GPT-2 small의 표: 50257 × 768 =', (50257 * 768).toLocaleString(), '개');

실행 결과: 두 줄이 똑같다(−0.554 −0.322 −0.105 1.065 −1.060 −0.498 −0.403 −0.011). 표는 279 × 8 = 2,232개, GPT-2 small은 38,597,376개.

핵심: 그래서 실제 구현은 곱셈 없이 행을 꺼낸다(nn.Embedding). 차이는 채우는 방법: 오늘은 세서, LLM은 무작위에서 시작해 역전파로. 4주차에 직접 학습한다.

작은 코퍼스의 정직한 한계

  • “임베딩”의 이웃(SVD 30): 공간 .66 · 비용 .65 · 실수 .65 · 벡터 .65 · 못 .63
  • 유추 “청킹 : 청크 = 임베딩 : ?” → 임베딩해 · 벡터스토어 · 저장
  • 유추 “확률 : 온도 = 검색 : ?” → 리랭킹 · 순위 · 정확도 ≈ “검색”의 이웃 그대로

1,626단어로는 방향이 안정되지 않는다. 대규모 모델은 수십억 단어로 같은 일을 한다

“왕 − 남자 + 여자 ≈ 여왕”은 수십억 단어로 학습한 word2vec에서 나온 결과다. 여기서는 b − a가 의미 있는 방향이 되지 못하고, 답이 c(검색)의 이웃으로 끌려간다. 벡터 산술이 아니라 “c 근처 찾기”가 된 것.

이것을 실패가 아니라 “데이터 양이 왜 중요한가”의 증거로 쓴다 → 9주차 스케일링 예고.

정리

  • 원-핫: 모든 코사인 0 → 비슷함을 모른다
  • 분포 가설: 창 안의 이웃을 센 행 = 단어 벡터
  • PPMI로 흔한 단어의 힘을 빼고, SVD로 k차원 밀집 벡터로 압축
  • “어휘 × d” 표 = LLM 첫 층. LLM은 역전파로 채운다
  • RAG 5주차: 같은 코사인 검색을 문장 임베딩(multilingual-e5)으로

다음 주 · 신경망 언어 모델과 학습

표를 세지 않고 학습한다: 임베딩 → 소프트맥스 → 교차 엔트로피 → 자동 미분

C5는 과제로 낸다. 다음 주 시작 5분 동안 “k = 2에서 왜 모든 이웃의 코사인이 1인가?” 답을 확인한다(기대: 2차원에서는 방향이 원 위의 각도 하나뿐이라 279단어가 몇 방향에 몰린다).

const corpus = await (await fetch('/assets/data/corpus/corpus.json')).json();
const words = corpus.documents.flatMap((d) => tokenizeWords(d.text));
const vocab = [...new Set(words)].sort();
console.log('단어 수:', words.length, '어휘 크기 V:', vocab.length);
console.log('첫 문장의 단어:', words.slice(0, 8).join(' | '));
function oneHot(word) {
  const v = new Array(vocab.length).fill(0);
  v[vocab.indexOf(word)] = 1;
  return v;
}
function cosine(a, b) {
  let dot = 0, na = 0, nb = 0;
  for (let i = 0; i < a.length; i++) {
    dot += a[i] * b[i];
    na += a[i] * a[i];
    nb += b[i] * b[i];
  }
  return na === 0 || nb === 0 ? 0 : dot / Math.sqrt(na * nb);
}
function distance(a, b) {
  let s = 0;
  for (let i = 0; i < a.length; i++) s += (a[i] - b[i]) ** 2;
  return Math.sqrt(s);
}
const probe = ['확률', '온도', '토큰', '실습실'];
console.table(probe.map((a) => Object.fromEntries([['단어', a], ...probe.map((b) => [b, +cosine(oneHot(a), oneHot(b)).toFixed(3)])])));
console.log('거리(확률, 온도) =', distance(oneHot('확률'), oneHot('온도')).toFixed(3));
console.log('거리(확률, 실습실) =', distance(oneHot('확률'), oneHot('실습실')).toFixed(3));

import { corpusWords } from '/assets/js/core/cooc.js';
const corpus = await (await fetch('/assets/data/corpus/corpus.json')).json();
const docs = corpusWords(corpus);
console.log('첫 문서 앞부분:', docs[0].slice(0, 10).join(' '));
function countWindow(docs, window) {
  const table = new Map();
  for (const doc of docs) {
    for (let i = 0; i < doc.length; i++) {
      const row = table.get(doc[i]) ?? new Map();
      table.set(doc[i], row);
      for (let j = Math.max(0, i - window); j <= Math.min(doc.length - 1, i + window); j++) {
        if (j === i) continue;
        row.set(doc[j], (row.get(doc[j]) ?? 0) + 1);
      }
    }
  }
  return table;
}
function topContexts(table, word, k = 8) {
  return [...(table.get(word) ?? [])]
    .map(([ctx, count]) => ({ ctx, count }))
    .sort((a, b) => b.count - a.count)
    .slice(0, k);
}
for (const w of [1, 3]) {
  const table = countWindow(docs, w);
  console.log(`창 ±${w}: “확률” 행의 0 아닌 칸 수 =`, table.get('확률')?.size ?? 0);
  console.table(topContexts(table, '확률'));
}

function cosine(a, b) {
  let dot = 0, na = 0, nb = 0;
  for (let i = 0; i < a.length; i++) {
    dot += a[i] * b[i];
    na += a[i] * a[i];
    nb += b[i] * b[i];
  }
  return na === 0 || nb === 0 ? 0 : dot / Math.sqrt(na * nb);
}
function nearest(word, k = 8) {

  }
  return out.sort((a, b) => b.sim - a.sim).slice(0, k);
}

import { corpusWords, buildVocab, cooccurrence, matrix, row, nearest } from '/assets/js/core/cooc.js';

const docs = corpusWords(corpus);
const vocab = buildVocab(docs, 2);
const C = cooccurrence(docs, vocab, 3);
const n = vocab.size;
function ppmi(C) {
  const M = matrix(n, n);
  const rowSum = new Float64Array(n);
  let total = 0;
  for (let i = 0; i < n; i++) {
    for (let j = 0; j < n; j++) rowSum[i] += C.data[i * n + j];
    total += rowSum[i];
  }
  for (let i = 0; i < n; i++) {
    for (let j = 0; j < n; j++) {
      const c = C.data[i * n + j];
      if (c === 0) continue;
      const pmi = Math.log((c * total) / (rowSum[i] * rowSum[j]));
      if (pmi > 0) M.data[i * n + j] = pmi;
    }
  }
  return M;
}
const P = ppmi(C);
const top = (M, w, k = 5) => nearest(M, vocab.index.get(w), k, vocab.words).map((r) => `${r.word} ${r.sim.toFixed(2)}`).join(', ');

}

function hubs(M, k = 5) {
  const seen = new Map();
  for (let i = 0; i < n; i++) {
    for (const r of nearest(M, i, k, vocab.words)) seen.set(r.word, (seen.get(r.word) ?? 0) + 1);
  }
  return [...seen].sort((a, b) => b[1] - a[1]).slice(0, 5).map(([w, c]) => `${w}(${c})`).join(', ');
}

import { corpusWords, buildVocab, cooccurrence, ppmi, truncatedSVD, nearest, row } from '/assets/js/core/cooc.js';
const corpus = await (await fetch('/assets/data/corpus/corpus.json')).json();
const docs = corpusWords(corpus);
const vocab = buildVocab(docs, 2);
const P = ppmi(cooccurrence(docs, vocab, 3));
const id = (w) => vocab.index.get(w);
const probe = vocab.words.slice(0, 50).map(id);
const rows = [];
for (const k of [2, 5, 10, 30, 100]) {
  const S = truncatedSVD(P, k).vectors;
  let overlap = 0, top1 = 0;
  for (const i of probe) {
    const a = nearest(S, i, 8);
    const b = new Set(nearest(P, i, 8).map((r) => r.id));
    overlap += a.filter((r) => b.has(r.id)).length;
    top1 += a[0].sim;
  }
  rows.push({
    k,
    '겹친 이웃 (8개 중)': +(overlap / probe.length).toFixed(2),
    '1등 이웃 코사인': +(top1 / probe.length).toFixed(3),
    '확률의 이웃': nearest(S, id('확률'), 3, vocab.words).map((r) => r.word).join(' '),
  });
}
console.table(rows);
function unit(v) {
  const n = Math.hypot(...v);
  return n === 0 ? v : v.map((x) => x / n);
}
function analogy(M, a, b, c, k = 5) {
  const [va, vb, vc] = [a, b, c].map((w) => unit(row(M, id(w))));
  const q = new Float64Array(M.cols);
  for (let j = 0; j < M.cols; j++) q[j] = vb[j] - va[j] + vc[j];
  const qn = unit(q);
  const skip = new Set([a, b, c].map(id));
  const scored = [];
  for (let i = 0; i < M.rows; i++) {
    if (skip.has(i)) continue;
    const v = unit(row(M, i));
    let dot = 0;
    for (let j = 0; j < M.cols; j++) dot += v[j] * qn[j];
    scored.push({ word: vocab.words[i], sim: dot });
  }
  return scored.sort((x, y) => y.sim - x.sim).slice(0, k).map((r) => `${r.word} ${r.sim.toFixed(2)}`);
}
const S30 = truncatedSVD(P, 30).vectors;
for (const [a, b, c] of [['청킹', '청크', '임베딩'], ['확률', '온도', '검색']]) {
  console.log(`${a} : ${b} = ${c} : ?  →`, analogy(S30, a, b, c).join(', '));
  console.log(`   (참고) ${c}의 이웃 →`, nearest(S30, id(c), 5, vocab.words).map((r) => r.word).join(', '));
}
