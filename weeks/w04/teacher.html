  • 온도 T로 나누면: T = 0.1 → [1, 0, …] (argmax) · T = 10 → 거의 균등

과신한 오답 손실은 C2 정답 실행 결과다. “모르는 것보다 틀린 확신이 4배 나쁘다.”

“교차 엔트로피”라는 이름은 정답 분포(원-핫)와 모델 분포 사이의 교차 엔트로피 −Σ y log p에서 왔다. 원-핫이면 정답 항 하나만 남는다고만 짚는다.

어느 쪽으로 고치나: ∂L/∂z = p − onehot

습 (정답)수제 · 은 · 에␣
p0.4410.1790.1090.054
p − y−0.559 ↑+0.179 ↓+0.109 ↓+0.054 ↓
  • 정답은 (1 − p)만큼 올리고, 오답은 자기 확률만큼 내린다 · 경사의 합 = 0
  • z ← z − 1.0 × 경사 한 걸음 → 손실 0.819 → 0.495
  • 수치 미분 (L(z+h) − L(z−h)) / 2h 과의 차이 1.07 × 10−11

유도는 칠판에서 2줄로: L = −z_t + log Σ exp(z_j) → ∂L/∂z_i = −[i = t] + exp(z_i)/Σ = p_i − y_i. 수식이 어려운 반은 유도를 건너뛰고 위젯으로 “정말 그렇게 움직인다”를 보여 준다.

7주차 tensor.js의 crossEntropy 역전파가 바로 이 한 줄(dL += g * probs; dL[target] -= g)이라는 것을 예고한다.

시연 순서 (결과는 오른쪽 실행 결과 창)

  1. 처음 상태: 오답 “수”가 1등(39.6%), p(습) = 14.6%, 손실 1.926 — 균등 추측(1.792)보다 나쁘다
  2. ⬇ 경사 하강 1스텝 → 습 ↑, 수가 가장 많이 ↓, 손실 1.081. 몇 번 더 눌러 손실이 0으로 가는 것을 본다
  3. “빈도표처럼” → p(습) = 7/17 = 41.2%. “로짓 = log 횟수이면 소프트맥스가 곧 빈도표”
  4. “과신한 오답” → 손실 9.50, 균등의 5.3배. 손실 곡선의 점이 왼쪽 위 끝으로 간다
  5. T → 0 → 1등이 100%. 정답이 1등이 아니면 손실 20.0

역전파 = 계산 그래프 위의 연쇄 법칙

y = tanh(w·x + b)        x = 2, w = −0.4, b = 0.2
순전파:  w·x = −0.8 → n = −0.6 → y = −0.537
역전파:  ∂y/∂n = 1 − y² = 0.712
         ∂y/∂b = 0.712 × 1 = 0.712
         ∂y/∂w = 0.712 × x = 1.423
         ∂y/∂x = 0.712 × w = −0.285
  • 덧셈은 경사를 그대로 · 곱셈은 상대편 값을 곱해 · 여러 곳에 쓰였으면 더한다
  • 노드의 경사 = 위에서 내려온 경사 × 국소 미분

칠판에 그래프를 그리고 학생에게 역전파 칸을 채우게 한다. 순전파는 왼쪽 → 오른쪽, 역전파는 오른쪽 → 왼쪽.

“자동 미분은 기호 미분(수식을 미분)도 수치 미분(흔들어 보기)도 아니다. 연산마다 국소 미분을 기억해 두었다가 곱해 나가는 것.”

데모 · 자동 미분 그래프

시연 순서

  1. 처음: 값은 다 있고 경사는 “?”. L = 1.479
  2. ② 역전파 → L에서 왼쪽으로 한 칸씩 채워진다. w₁ 노드 클릭: ∂L/∂w₁ = −1.184 × 2 = −2.369
  3. n, s, x₁·w₁, x₂·w₂, b가 모두 −1.184인 이유(덧셈 노드)를 묻는다
  4. lr 0.05로 ③ 몇 번 → 1.479 → 0.993 → 0.353 → 0.061 … 7스텝이면 0.001 아래
  5. ↺ → lr 0.4 · 10스텝 두 번 → 손실이 0.01~0.07 사이에서 오르내린다(진동)
  6. ↺ → lr 1.0 · 1스텝 → n = 6.20, 1 − h² ≈ 1.6 × 10−5, 손실 0.25에서 영원히 멈춤(포화 · 경사 소실)

자동 미분, 코드 네 줄

import { Value } from '/assets/js/core/value.js';
const x = new Value(2), w = new Value(-0.4), b = new Value(0.2);
const y = w.mul(x).add(b).tanh();   // 순전파: 그래프가 만들어진다
y.backward();                       // 역전파: 모든 grad가 채워진다
console.log('y =', y.data.toFixed(4));
console.log('∂y/∂w =', w.grad.toFixed(4), '· ∂y/∂b =', b.grad.toFixed(4), '· ∂y/∂x =', x.grad.toFixed(4));

곱셈 노드가 기억하는 것: this.grad += other.data * out.grad — 그게 전부다

실행 결과: y = −0.5370 · ∂y/∂w = 1.4232 · ∂y/∂b = 0.7116 · ∂y/∂x = −0.2846 (슬라이드 8과 같다).

value.js의 mul · add · tanh의 _backward를 화면에 띄워 함께 읽는다. 각각 한두 줄이다.

학습 루프 = 순전파 · 역전파 · 경사 하강

import { Value } from '/assets/js/core/value.js';
// 위젯과 같은 뉴런: L = (tanh(2·w1 − 1·w2 + b) − 0.5)²
for (const lr of [0.05, 0.4, 1.0]) {
  let w1 = -0.4, w2 = 0.3, b = 0.2;
  const hist = [];
  for (let step = 0; step < 12; step++) {
    const [W1, W2, B] = [w1, w2, b].map((v) => new Value(v));
    const L = W1.mul(2).add(W2.mul(-1)).add(B).tanh().sub(0.5).pow(2); // 순전파
    L.backward();                                                      // 역전파
    hist.push(L.data.toFixed(3));
    w1 -= lr * W1.grad; w2 -= lr * W2.grad; b -= lr * B.grad;          // 경사 하강
  }
  console.log(`lr ${lr}:`, hist.join(' '));
}

실행 결과: lr 0.05 → 1.479 0.993 0.353 0.061 0.015 … 0.000 / lr 0.4 → 1.479 0.211 0.197 0.169 0.111 0.012 0.020 0.061 0.007 0.024 0.024 0.072 (진동) / lr 1 → 1.479 0.250 0.250 …(포화).

한 스텝 = 순전파 → 역전파 → 경사 하강. “7주차 GPT 학습 루프도 이 세 줄이다.”

핵심: “실” 행의 손실 Σ 횟수 × (−log p)는 p = 횟수 ÷ 합일 때 최소다. 빈도표는 이 최적화의 답을 한 번에 적어 둔 것이다. 그러니 신경망 바이그램으로는 얻는 것이 없다 — 이득은 문맥을 넓힐 때(다음 슬라이드).

lr이 200처럼 커 보이는 이유: 평균 손실이라 행마다의 경사가 (그 글자 등장 수 / 6,827)배로 작다. 드문 글자의 행은 lr 200에서도 천천히 배운다.

발문: “앞 3글자 대신 앞 100글자를 보려면?” → 입력이 100 × 16 = 1600차원, 자리마다 다른 가중치 → 5주차 어텐션.

정리

  • 로짓 → 소프트맥스 → 확률 · 손실 = −log p(정답) (= 1주차 NLL)
  • 로짓의 경사 = p − onehot · 역전파 = 그래프 위의 연쇄 법칙
  • w ← w − lr × 경사 · lr이 크면 진동하거나 포화로 멈춘다
  • 신경망 바이그램 ≈ 빈도표 · 이득은 문맥을 넓힐 때 (MLP 4.075 vs 4-gram 5.645)

const cands = ['습', '수', '제', '은', '에', '␣']; // "실" 다음 후보
const z = [3.0, 2.1, 1.6, 1.6, 1.6, 0.9];         // 모델이 낸 점수(로짓)

function softmaxNaive(z) {
  const e = z.map(Math.exp);
  const s = e.reduce((a, b) => a + b, 0);
  return e.map((x) => x / s);
}
function softmax(z, T = 1) {
  const m = Math.max(...z);                          // 가장 큰 값을 빼도 결과는 같다
  const e = z.map((x) => Math.exp((x - m) / T));
  const s = e.reduce((a, b) => a + b, 0);
  return e.map((x) => x / s);
}
const p = softmax(z);
console.table(cands.map((c, i) => ({ c, z: z[i], exp: +Math.exp(z[i]).toFixed(3), p: +p[i].toFixed(4) })));
console.log('합:', p.reduce((a, b) => a + b, 0));
const big = z.map((x) => x + 1000);
console.log('naive(z+1000):', softmaxNaive(big).map((x) => +x.toFixed(4)));
console.log('stable(z+1000):', softmax(big).map((x) => +x.toFixed(4)));
for (const T of [0.1, 0.5, 1, 2, 10]) console.log(`T=${T}`, softmax(z, T).map((x) => +x.toFixed(3)).join(' '));

부록 B · C2 정답

const cands = ['습', '수', '제', '은', '에', '␣'];
function softmax(z) {
  const m = Math.max(...z);
  const e = z.map((x) => Math.exp(x - m));
  const s = e.reduce((a, b) => a + b, 0);
  return e.map((x) => x / s);
}
const crossEntropy = (z, t) => -Math.log(softmax(z)[t]);
const gradCE = (z, t) => softmax(z).map((p, i) => p - (i === t ? 1 : 0)); // p − onehot

const z = [3.0, 2.1, 1.6, 1.6, 1.6, 0.9];
const t = 0; // 정답 "습"
const g = gradCE(z, t);
const h = 1e-5;
const num = z.map((_, i) => {
  const zp = z.slice(), zm = z.slice();
  zp[i] += h; zm[i] -= h;
  return (crossEntropy(zp, t) - crossEntropy(zm, t)) / (2 * h);
});
console.log('손실 L =', crossEntropy(z, t).toFixed(4));
console.table(cands.map((c, i) => ({ c, analytic: +g[i].toFixed(6), numeric: +num[i].toFixed(6) })));

import { charVocab } from '/assets/js/core/text.js';
const corpus = await (await fetch('/assets/data/corpus/corpus.json')).json();
const text = corpus.documents.map((d) => d.text).join('\n\n');
const vocab = charVocab(text);
const V = vocab.size; // 495
const ids = vocab.encode(text);
const xs = ids.slice(0, -1), ys = ids.slice(1); // (앞 글자, 다음 글자) 예시 6,827개
const N = xs.length;

// 1주차 방식: 세어서 나눈 바이그램의 학습 NLL (비교 기준)
const C = new Float64Array(V * V);
const rowN = new Float64Array(V);
for (let i = 0; i < N; i++) { C[xs[i] * V + ys[i]]++; rowN[xs[i]]++; }
let countNLL = 0;
for (let i = 0; i < N; i++) countNLL -= Math.log(C[xs[i] * V + ys[i]] / rowN[xs[i]]);
countNLL /= N;

// 신경망 바이그램: logits = onehot(x) · W = W의 x번째 행
const W = new Float64Array(V * V); // 0으로 시작 → 처음엔 모든 글자가 1/495
const grad = new Float64Array(V * V);
const p = new Float64Array(V);
const LR = 200, STEPS = 300;
const log = [];
for (let step = 0; step <= STEPS; step++) {
  grad.fill(0);
  let loss = 0;
  // 같은 앞 글자 a를 가진 예시는 로짓이 같다 → 행마다 소프트맥스를 한 번만 계산한다
  for (let a = 0; a < V; a++) {
    if (!rowN[a]) continue;
    const o = a * V;
    let max = -Infinity;
    for (let b = 0; b < V; b++) max = Math.max(max, W[o + b]);
    let sum = 0;
    for (let b = 0; b < V; b++) sum += (p[b] = Math.exp(W[o + b] - max));
    for (let b = 0; b < V; b++) {
      const q = p[b] / sum;
      if (C[o + b]) loss -= C[o + b] * Math.log(q);   // 예시 C[a][b]개의 −log p
      grad[o + b] = (rowN[a] * q - C[o + b]) / N;     // Σ (p − onehot) / N
    }
  }
  loss /= N;
  if (step % 50 === 0) log.push({ step, loss: +loss.toFixed(4), gap: +(loss - countNLL).toFixed(4) });
  if (step === STEPS) break;
  for (let j = 0; j < W.length; j++) W[j] -= LR * grad[j];
}
console.table(log);
console.log('빈도표 바이그램 NLL:', countNLL.toFixed(4));
// 학습된 W의 "실" 행을 소프트맥스하면 빈도표의 7/21, 3/21 … 에 가까워진다
const a = vocab.stoi.get('실'), o = a * V;
let max = -Infinity; for (let b = 0; b < V; b++) max = Math.max(max, W[o + b]);
let sum = 0; for (let b = 0; b < V; b++) sum += Math.exp(W[o + b] - max);
console.table(['습', '수', '제', '은'].map((ch) => {
  const b = vocab.stoi.get(ch);
  return { ch, neural: +(Math.exp(W[o + b] - max) / sum).toFixed(3), count: +(C[o + b] / rowN[a]).toFixed(3) };
}));

import { Tensor, embedding, linear, add, gelu, crossEntropy, backward, noGrad, AdamW } from '/assets/js/core/tensor.js';
import { countNgrams, nll } from '/assets/js/core/ngram.js';
import { mulberry32 } from '/assets/js/core/rng.js';
const corpus = await (await fetch('/assets/data/corpus/corpus.json')).json();
const join = (docs) => docs.map((d) => d.text).join('\n\n');
const trainText = join(corpus.documents.filter((d) => d.id !== 'rag-vectordb'));
const valText = join(corpus.documents.filter((d) => d.id === 'rag-vectordb'));

// 어휘: 코퍼스 전체 글자 495개 + 시작 표시 BOS
const chars = [...new Set(trainText + valText)].sort();
const stoi = new Map(chars.map((c, i) => [c, i]));
const V = chars.length, BOS = V;
const CTX = 3, D = 16, H = 32; // 앞 3글자 · 임베딩 16차원 · 은닉 32

function makeExamples(text) {
  const ids = [...Array(CTX).fill(BOS), ...[...text].map((c) => stoi.get(c))];
  const X = [], Y = [];
  for (let i = CTX; i < ids.length; i++) { X.push(ids.slice(i - CTX, i)); Y.push(ids[i]); }
  return { X, Y };
}
const train = makeExamples(trainText), val = makeExamples(valText);

const rand = mulberry32(1);
const E = Tensor.randn([V + 1, D], 1, rand);                                    // 글자 임베딩 표
const W1 = [0, 1, 2].map(() => Tensor.randn([D, H], 1 / Math.sqrt(CTX * D), rand)); // 자리마다 하나
const b1 = Tensor.zeros([H], true);
const W2 = Tensor.randn([H, V], 0.5 / Math.sqrt(H), rand);
const b2 = Tensor.zeros([V], true);
const params = [E, ...W1, b1, W2, b2];

function forward(X) {
  // h = gelu( Σ_j E[x_j] · W1_j + b1 )  ← [E[x1] | E[x2] | E[x3]] · W1 을 자리별로 나눈 것
  let h = null;
  for (let j = 0; j < CTX; j++) {
    const z = linear(embedding(E, X.map((x) => x[j])), W1[j], j === 0 ? b1 : null);
    h = h ? add(h, z) : z;
  }
  return linear(gelu(h), W2, b2); // logits [N, V]
}
const evalNLL = (set) => noGrad(() => crossEntropy(forward(set.X), set.Y).data[0]);

const opt = new AdamW(params, { lr: 0.01, weightDecay: 0.5 });
const log = [];
for (let step = 1; step <= 600; step++) {
  const idx = Array.from({ length: 32 }, () => Math.floor(rand() * train.X.length));
  const loss = crossEntropy(forward(idx.map((i) => train.X[i])), idx.map((i) => train.Y[i]));
  opt.zeroGrad();
  backward(loss);
  opt.step();
  if (step % 200 === 0) log.push({ step, batchLoss: +loss.data[0].toFixed(3), valNLL: +evalNLL(val).toFixed(3) });
}
console.table(log);

const valToks = [...valText];
const count = (n) => nll(countNgrams([...trainText], n), valToks, { k: 0.1 }).nll;
console.table([
  { model: '빈도 바이그램 (앞 1글자, k=0.1)', valNLL: +count(2).toFixed(3) },
  { model: '빈도 트라이그램 (앞 2글자, k=0.1)', valNLL: +count(3).toFixed(3) },
  { model: '빈도 4-gram (앞 3글자, k=0.1)', valNLL: +count(4).toFixed(3) },
  { model: 'MLP (앞 3글자, 임베딩 16)', valNLL: +evalNLL(val).toFixed(3), trainNLL: +evalNLL(train).toFixed(3) },
]);
console.log('파라미터 수:', params.reduce((s, p) => s + p.size, 0));
