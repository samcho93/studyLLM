오늘은 새 알고리즘보다 “조립”이 주제다. 칠판 한쪽에 [B, T, D]를 크게 써 두고 수업 내내 모양을 부르며 진행한다.

어텐션 하나로 GPT가 될까?

  1. 순서를 모른다 — “5-3=”과 “3-5=”가 같은 입력이 된다
  2. 섞기만 한다 — 출력은 값 벡터의 가중 평균, 토큰별 가공이 없다
  3. 깊이 쌓을 수 없다 — 층을 지날수록 신호가 사라지거나 폭발한다

블록 = 교환(어텐션) + 생각(피드포워드) + 배관(잔차 · 정규화)

발문: “지난주 어텐션 계산기에서 토큰 순서를 바꾸면 점수 표는 어떻게 되었나?” → 행과 열이 같이 뒤바뀌기만 한다. 오늘 그것을 정확히 확인한다.

세 문제 각각이 오늘의 부품 하나에 대응한다: 위치 임베딩, 피드포워드, 잔차 연결 + 층 정규화.

오늘 할 수 있게 되는 것

  1. 순전파의 각 지점에서 텐서 모양을 적는다 ([B, T, D] · [B, H, T, T] · [B, T, V])
  2. 위치 정보가 왜 필요한지, 잔차 연결 · 층 정규화가 무엇을 하는지 설명한다
  3. 설정으로 파라미터 수를 세고 paramCount로 검증한다 (블록 ≈ 12·D²)

오늘 조립한 모델(106,959개)을 다음 주에 그대로 학습시킨다고 먼저 알려 동기를 준다.

GPT = 임베딩 → 블록 × L → 헤드

x = wte[id] + wpe[pos]                   [B, T, D]
for each block (× L):
    x = x + 어텐션(층정규화(x))            [B, T, D]
    x = x + 피드포워드(층정규화(x))        [B, T, D]
logits = 헤드(층정규화(x))               [B, T, V]
  • 블록을 지나도 모양이 그대로 → 몇 개든 쌓을 수 있다
  • core/gpt.js의 forward가 정확히 이 다섯 줄이다

assets/js/core/gpt.js의 forward 함수를 화면에 띄워 이 슬라이드와 한 줄씩 맞춰 본다. add(x, …)가 잔차 연결이다.

용어는 코퍼스의 “트랜스포머 블록” 문서와 같게 쓴다: 잔차 연결, 층 정규화, 위치 임베딩, 피드포워드.

모양을 따라가면 구조가 보인다

T가 두 번 들어가는 곳은 어텐션 점수뿐이다. T를 2배 → 점수는 4배(C1 결과). 긴 문맥이 비싼 이유이며 9주차 메모리 계산에서 다시 나온다.

core/gpt.js는 [B, T, D]를 [B·T, D]로 펼쳐 저장한다. 학생이 logits.shape가 [192, 495]로 나와 당황하면 “B·T = 4·48 = 192”를 짚는다.

“5-3=”과 “3-5=”는 같은 입력?

숫자는 위치 위젯 기본 화면(층 정규화 + 어텐션 한 층, D = 16, seed 고정 무작위 가중치, 학습형 위치 임베딩)과 같다. 학습된 모델이어도 결론은 같다: 식 자체가 합이기 때문이다.

1×10⁻¹⁶이 0이 아닌 이유: 부동소수점 덧셈은 순서에 따라 마지막 자리가 달라진다. 수학적으로는 0이다.

단서: 인과 마스크 층을 여러 개 쌓으면 “앞에 몇 개가 있나”가 새어 들어가 위치 임베딩 없이도 순서가 약간 드러난다(C5). 우수 학생용 심화 이야기로 남겨 둔다.

둘 다 “토큰마다 따로” 계산한다는 공통점을 강조한다. 토큰끼리 섞는 곳은 블록 전체에서 어텐션 하나뿐이다.

배치 정규화(MLBasic에서 봤을 수도 있음)와의 차이: 배치 정규화는 배치 방향으로, 층 정규화는 특징(D) 방향으로 평균을 낸다. 문장 길이와 배치 크기가 들쭉날쭉한 언어 모델에는 층 정규화가 맞다.

GPT-2는 출력 헤드가 wte를 공유하고 헤드 편향이 없다. 우리 core/gpt.js는 헤드를 따로 둔다. 같은 설정을 우리 구조로 만들면 163,087,441개다.

요즘 모델(Llama 등)은 RMSNorm · SwiGLU · RoPE · GQA로 부품이 조금 다르다. 예: Llama 3 8B 공개 설정으로 세면 약 80.3억 개. 해부도 위젯의 “요즘 LLM” 접기 상자를 참고한다. 정확한 비교는 9주차에 한다.

정리

  • GPT = 임베딩(+ 위치) → [층 정규화 → 어텐션 → + → 층 정규화 → 피드포워드 → +] × L → 헤드
  • 어텐션은 합이라 순서를 모른다 → 위치 임베딩
  • 잔차 = 신호 · 기울기의 고속도로, 층 정규화 = 입구의 크기 조절
  • 블록 ≈ 12·D², 어텐션 점수 메모리 ∝ T²

import { createModel, forward } from '/assets/js/core/gpt.js';
const cfg = { vocabSize: 495, blockSize: 48, nLayer: 2, nHead: 4, nEmbd: 48 };

function traceShapes({ vocabSize: V, nHead: H, nEmbd: D }, B, T) {
  const hs = D / H;
  const rows = [];
  const add = (stage, shape) => rows.push({ stage, shape: `[${shape.join(', ')}]`, count: shape.reduce((a, b) => a * b, 1) });
  add('입력 토큰 id', [B, T]);
  add('토큰 임베딩 + 위치 임베딩', [B, T, D]);
  add('층 정규화 ①', [B, T, D]);
  add('qkv 선형', [B, T, 3 * D]);
  add('헤드로 나눈 Q (K, V도 같다)', [B, H, T, hs]);
  add('어텐션 점수 QKᵀ', [B, H, T, T]);
  add('가중합 후 헤드 합치기', [B, T, D]);
  add('출력 투영 (+ 잔차)', [B, T, D]);
  add('층 정규화 ②', [B, T, D]);
  add('확장 fc', [B, T, 4 * D]);
  add('GELU', [B, T, 4 * D]);
  add('축소 proj (+ 잔차)', [B, T, D]);
  add('최종 층 정규화', [B, T, D]);
  add('로짓', [B, T, V]);
  add('마지막 위치 확률', [B, V]);
  return rows;
}

import { Tensor, layerNorm } from '/assets/js/core/tensor.js';

const mean = (a) => a.reduce((s, v) => s + v, 0) / a.length;
const variance = (a) => mean(a.map((v) => (v - mean(a)) ** 2));

function layerNormArr(x, gamma = null, beta = null, eps = 1e-5) {
  const m = mean(x);
  const v = variance(x);
  return x.map((xi, i) => {
    const h = (xi - m) / Math.sqrt(v + eps);
    return gamma ? h * gamma[i] + beta[i] : h;
  });
}

const x = [2, 4, 4, 4, 5, 5, 7, 9];
const y = layerNormArr(x);
console.log('y =', y.map((v) => +v.toFixed(3)));
console.log('평균', mean(y).toFixed(6), '분산', variance(y).toFixed(6));
const t = layerNorm(new Tensor(x, [1, 8]), Tensor.fill([8], 1), Tensor.zeros([8]));
console.log('tensor.js =', Array.from(t.data, (v) => +v.toFixed(3)));

const big = layerNormArr(x.map((v) => v * 100 + 1000));
console.log('100x + 1000 →', big.map((v) => +v.toFixed(3)));
console.log('[3,3,3,3] →', layerNormArr([3, 3, 3, 3]), '· eps 없으면 →', layerNormArr([3, 3, 3, 3], null, null, 0));
const g = layerNormArr(x, x.map(() => 2), x.map(() => 1));
console.log('γ=2, β=1 → 평균', mean(g).toFixed(4), '분산', variance(g).toFixed(4));

import { mulberry32, gaussian } from '/assets/js/core/rng.js';
const D = 64, DEPTH = 48;
const norm = (v) => Math.sqrt(v.reduce((s, x) => s + x * x, 0));
const cos = (a, b) => a.reduce((s, x, i) => s + x * b[i], 0) / (norm(a) * norm(b));
const matVec = (W, v) => W.map((row) => row.reduce((s, w, j) => s + w * v[j], 0)); // W · v
const matTVec = (W, g) => W[0].map((_, j) => W.reduce((s, row, i) => s + row[j] * g[i], 0)); // Wᵀ · g

/** DEPTH개의 무작위 층 W (D×D). 원소는 평균 0, 표준편차 gain/√D. */
function makeLayers(gain, seed = 1) {
  const rand = mulberry32(seed);
  return Array.from({ length: DEPTH }, () => Array.from({ length: D }, () => Array.from({ length: D }, () => (gaussian(rand) * gain) / Math.sqrt(D))));
}

function run(gain, residual) {
  const layers = makeLayers(gain);
  const r = mulberry32(99);
  const x0 = Array.from({ length: D }, () => gaussian(r));
  let x = x0;
  const norms = [norm(x)];
  for (const W of layers) {
    const f = matVec(W, x);
    x = residual ? x.map((v, i) => v + f[i]) : f;
    norms.push(norm(x));
  }
  // 역전파: 맨 위에서 크기 1인 기울기 g를 아래로 보낸다
  let g = Array.from({ length: D }, () => 1 / Math.sqrt(D));
  for (let l = DEPTH - 1; l >= 0; l--) {
    const back = matTVec(layers[l], g);
    g = residual ? g.map((v, i) => v + back[i]) : back;
  }
  return { norms, cosIn: cos(x, x0), grad: norm(g) };
}

const rows = [];
for (const [gain, residual] of [[0.8, false], [1.0, false], [1.2, false], [0.1, true], [0.5, true]]) {
  const res = run(gain, residual);
  rows.push({
    설정: `${residual ? '잔차 있음' : '잔차 없음'} · gain ${gain}`,
    '|x| 0층': +res.norms[0].toFixed(2),
    '|x| 12층': +res.norms[12].toPrecision(3),
    '|x| 48층': +res.norms[DEPTH].toPrecision(3),
    'cos(x48, x0)': +res.cosIn.toFixed(3),
    '입력 기울기 |g|': +res.grad.toPrecision(3),
  });
}
